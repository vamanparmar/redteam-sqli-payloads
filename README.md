## Overview

This repository contains a **categorized collection of SQL Injection payloads** used for:

- Penetration Testing
- Bug Bounty Hunting
- Red Team Operations
- Security Research
- Web Application Vulnerability Testing

The payloads are organized based on **SQL Injection techniques** to make testing easier for security researchers.

---

# Payload Categories

| Category | Description |
|--------|-------------|
| Boolean Based SQLi | Detect vulnerabilities using true/false responses |
| Comment Based SQLi | Bypass filters using SQL comments |
| DNS Exfiltration SQLi | Extract data through DNS queries |
| Error Based SQLi | Trigger database errors to leak information |
| Hybrid SQLi | Combination of multiple SQLi techniques |
| OOB SQLi | Out-of-band data extraction |
| Second Order SQLi | Payload stored and executed later |
| Authentication Bypass | Login bypass payloads |
| General SQL Injection | Common testing payloads |
| Stacked Queries | Execute multiple SQL commands |
| Stored Procedure SQLi | Exploit database stored procedures |
| Time Based SQLi | Detect vulnerabilities via response delay |
| Union Based SQLi | Extract data using UNION queries |
| WAF Bypass SQLi | Payloads designed to bypass firewalls |
